# Proyecto: web de gasolineras (MVP)
Objetivo: web instalable en móvil con las gasolineras más baratas, con mapa. Sin registro ni datos personales.
Stack: Next.js + Supabase. Mapas: MapLibre con OpenStreetMap.
Datos: API REST gratuita del Ministerio de Transición Ecológica (precios de carburantes).
Reglas:
- Un paso cada vez. Antes de programar, explícame el plan en pocas líneas.
- No guardes datos personales ni ubicación de usuarios.
- Si la API falla, mostrar el último dato guardado con su fecha.
- Idioma de la interfaz: español.
Fuera del MVP: parkings, dejar plaza, cuentas, pagos, app nativa.
